# PI 状态仅向系统管理员投影

PI 配置与运行状态属于系统运维信息：普通用户无法据此采取修复动作，常驻正常状态还会把 PI 误解为成员、Agent 或用户可配置能力。AgentBean 因此不向普通用户公开 PI 状态或诊断接口；配置就绪、未来的运行健康与紧急停止状态只向系统管理员投影，异常时由管理员侧栏提供不可忽略的入口，具体诊断留在 System Admin Console。普通用户只获得当前操作的适当结果，不暴露 PI、Provider、Model 或诊断身份；本决策取代 ADR-0031 中“Team 与普通用户只看到 PI 状态”的可见性边界，不改变其禁止隐式跨模型 fallback 的决定。
