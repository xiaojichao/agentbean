表格字段说明
  • 名称 = 文件名 + 产物集合 ID；类型 / 阶段 = 项目语义，不是文件来源。
  • 来源 = Agent、人类修改、WorkspaceRun 和消息位置。
  • 当前版 = currentVersionId，代表最新 Server 修订；最终版 = finalVersionId，代表人工确认指针。
  • 审核 = 当前版本是否可被后续引用；动作最终必须写回 Server 事实。
整包引用规则
  • 整包引用当前版本时，读取包内每个产物集合各自的 currentVersionId。
  • 用户手动修改和 Agent 修订都以 Server 最新修订为准，不回退到聊天旧正文。
  • 提交给后端时必须携带 artifactVersionId 或 artifactCollectionId，不能只传 F1/F2 或“第 3 个”。
